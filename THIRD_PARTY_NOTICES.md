The chess piece artwork in `assets/pieces` is the Chessnut piece set from
[Lichess](https://github.com/lichess-org/lila/tree/master/public/piece/chessnut),
used under the Apache License 2.0. The artwork has not been modified.

That last sentence is a decision, not a leftover. The design pass offered to
recolour the set to `#FBF7EC` / `#16130D` so it sat in the same two-tone system
as the board and the mark; the board supplies the warmth instead, the set keeps
its own black and white outlines, and this notice stays true without anyone
having to remember to amend it. If the artwork is ever recoloured, this
paragraph and the sentence above it change in the same commit.
