# Test whether current interior ordering leaves room for a learned prior

The small speed trials and interrupted-pass shadow rule are closed through PR #123 head d6c8396e4efdf61445fdc4bf914907da937564a6. This audit tests whether Schness spends search on the wrong ordinary interior branches often enough to warrant a position-conditioned ranker. It does not train a model, change engine behavior, reuse the failed ridge data, or treat its own finite-horizon scores as truth.

Generate 32 fresh legal paths from the quiet six-slot capture-bank start with sorted legal action keys and one LCG stream (1664525, 1013904223, modulus 2^32), seed 20263523. Repeat targets 8, 16, 24, 32 plies. Keep terminal and incomplete paths without replacement. Archive transcripts, path IDs and initial/final PRNG state. These positions are diagnostic only; exclude them and their path families from future training or validation.

Run a control and instrumented copy per path, iterative competitive depth 3, q4 checks on/evasion 2, LMR off, eval cache on/q cache off, reducePV on, other optional flags off, 100,000 nodes and 200 ms. Record exactly the first normal interior visit with remaining depth 2 that actually orders at least four legal actions, in traversal order. Preserve the full snapshot including repetition history and exact action order including current hints, killers and history; a terminal, cap, cache hit, or unavailable sample cannot be replaced by a later query. Record checks and the ordered action classes. Compare all jointly completed root decisions, scores, PVs, and node counts, with legal PV and exact caller restoration checks throughout.

For each sampled interior state, run exactly one frozen nonselective full-root-window MultiPV=2 label at each of depth 3 and depth 4, using the existing budgeted iterative behavior, no repetition preference, no RNG, same q/cache flags and 100,000 node/200 ms caps per query. MultiPV=2 must search every root action and report the best two; a stable label requires both searches complete, strict best-over-second at each depth, and the same best move. Retain disagreement and truncation separately. Measure rank of the stable best in the recorded actual order, including rank among quiet moves, and report by path and in-check/capture/drop/quiet strata. This is a finite-horizon proxy and says nothing about strength alone.

Require at least 28 jointly complete or terminal control/instrumented roots, no correctness discrepancies, at least 20 stable labels, and at least eight stable best moves ranked fourth or later (at least 25% of stable labels). Otherwise stop without expanding this workload. Passing justifies a separately preregistered data collection and one ranker; it does not authorize a match. Publish all paths, source, raw results, scripts, labels and logs.

Preflight clarification, before any queries: finite search caps force iterative deepening in the existing engine. The labels use only their requested final depth, and incomplete queries never label a move. Do not alter the search loop to force noniterative behavior. Root search and labels use identical frozen rules/runtime, with only the observation hook removed from the control and label arms.
