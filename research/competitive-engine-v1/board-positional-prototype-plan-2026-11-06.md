# Test one per-search cache for the exact positional subtotal

The observation-only audit at PR #123 head 1d3f92c4 found 2,758 repeated board layouts in 26,108 calls (10.56%, across 29 roots). This qualifies one prototype. Use a temporary copy of the audited engine. Behind a default-off option, create a map on the prepared reversible competitive search state; take the existing fixed-width 32-character board field from the exact position key by locating the two bank separators from the end. Use the field as a map key only when the board encoding and profile assumptions hold. Keep the map scoped to one prepared root and capped at 4,096 entries; when full, keep existing entries and compute misses normally. Cache only the white-positive positional subtotal. Keep geometry settings fixed for the search, and keep full static evaluation, transposition keys, repetition, rules, legal generation, and terminal adjudication on their existing paths. No second key strategy or cap tuning.

Before timing, check all 174 portable contract cases and 142 rule snapshots with the option available; compare deterministic competitive results with the option on and off, including action, score, nodes, PV, depth, variations, caller restoration and a node cap. Run targeted search, reversible and mate tests on the temporary implementation. Verify board field extraction against the ordered owner/piece representation on observed boards and ensure stored subtotal values agree with recomputation in a separate untimed verification path.

Run one ABBA comparison on the audit's exact 32 roots at depth 4, q4 with checks/evasion 2, LMR off, eval cache on, q cache off, reducePV on, optional flags off except the candidate, 100,000 nodes and 200 ms. At least 28 roots must complete or adjudicate in all arms, every jointly complete result must match, and candidate aggregate elapsed on jointly complete roots must be at least 5% lower. On the same roots, run one ABBA comparison at the production 100 ms settings (request 20, LMR on, same q/cache flags). Candidate mean completed depth must not decrease. Retain every query including terminal and incomplete roots. Record cache hits, misses and high-water entry count separately from timing. Stop on any failed gate; do not revise or rerun this mechanism. Publish invoked runtimes, settings, fixtures, scripts, inputs, logs and raw records. Efficiency alone does not authorize a match, adoption, or promotion.
