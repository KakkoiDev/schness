# Audit full legal generation used only for terminal detection

The search adapter requests the full legal count before calling terminal adjudication. Adjudication needs only zero versus nonzero, but an exact count or list may be reused later in the node. Measure only completed internal nodes where the terminal request was the sole consumer and produced more than one legal action. A later exact count or list request disqualifies that node. Check repetition draws separately; do not assume all nodes can skip generation.

Instrumentation only: record the count obtained during terminal adjudication and whether the same node's facts are called again. Observe completion on normal return only. Record counts by full-list versus count-only generation, ordinary versus quiescence nodes, and terminal versus nonterminal results. Sum count minus one for positive eligible nodes as an upper bound on accepted actions a first-legal probe might avoid. Denominator is the sum of legal counts first consumed by terminal checks at all completed internal nodes. Retain the first 12 eligible positions and counts. Do not implement early exit, change adjudication order, or change search/cache keys.

Run one instrumented and one uninstrumented pass on indices 0, 4, …, 124 of js-legal-recaptures.json. Use iterative depth 4, LMR off, q4 with checks, evasion 2, evaluation cache on, Q cache off, optional flags off, no RNG, 100,000 nodes and 200 ms per root. Retain all caps and require identical action, score, PV, nodes and depth on at least 28 jointly completed roots, plus legality and input restoration throughout. Instrumented timing is not a speed test.

Stop unless the maximum avoided accepted actions are at least 10% of the denominator and at least 8 roots have eligible nodes, with correctness gates met. A pass permits a separately planned default-preserving prototype with exact parity across all 36 rule presets and a cost test for duplicate generation. This diagnostic does not authorize an engine change, opponent query, match or production adoption. Archive the exact sample, invoked engine modules, plan, script, logs and every result.
