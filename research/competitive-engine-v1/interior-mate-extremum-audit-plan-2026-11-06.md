# Audit sibling work after a maximum mate score at an interior node

The positional cache prototype failed both timing gates and is closed at PR #123 head 51921b6a. This audit targets a distinct search decision. Schness terminal values are signed 1,000,000 plus remaining normal depth. At an interior node that already passed terminal adjudication, a maximizing child cannot exceed 1,000,000 + max(0, depth − 1), and a minimizing child cannot go below its negative, provided static values stay strictly inside the mate band and no path increases normal depth. A later sibling cannot improve an incumbent that reaches this limit. The current interior loops can still search siblings if their incoming window extends beyond that score. Root action selection and ties are out of scope.

Measure only. Instrument a frozen temporary runtime to count visited nodes inside sibling subtrees entered after that interior node first attains the appropriate extremum. Count each visit once even with nested qualifying subtrees. Preserve searches, window bounds, cache behavior, ordering, callbacks, and outputs. Count only siblings the ordinary search actually enters. Include normal and quiescence nodes, and record whether the bound was attained from a full, reduced or null-window child. Record an error for a nonterminal static value outside the mate band or a child value beyond the predicted extremum; these would invalidate the argument. A future optimization would require separate proof for cache bound classification, selective search, and unchanged root tie policy.
