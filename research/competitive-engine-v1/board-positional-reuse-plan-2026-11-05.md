# Audit repeated board geometry inside the JavaScript evaluator

Closed prior work: the first-legal terminal prototype failed its timing gate at PR #123 head 8a8ebb8f. This audit targets a different computation. The competitive evaluator computes a signed positional subtotal from pieces and attacks; reserve contents, turn, rights and repetition affect other terms or terminal adjudication. The existing full evaluation cache can miss when those fields differ even if the 16 board cells are identical.

Before proposing a cache, measure the fraction of actual competitive positional subtotal calls whose exact board has already occurred inside the same root search. Instrument a temporary copy to observe each call and compare every repeated subtotal for equality. Use the ordered 16 owner/piece codes as the audit identity; no reflection, history key changes, or table score reuse. Keep control decisions, options, and rules intact. Never substitute a cached value in this audit.

Generate 32 fresh deterministic roots by starting each path at the same shared quiet six-slot capture-bank start and sampling legal actions uniformly from a single PRNG stream seeded 20263217. Use 8, 16, 24 and 32 plies in repeating order, retain any terminal roots, and archive all actions, final positions and PRNG state. Do not filter by evaluation, repetition, outcome or prior loss. Each root gets one control and one instrumented query, iterative competitive depth 4, q4 with checks/evasion 2, LMR off, eval cache on, q cache off, reducePV on, optional features off, 100,000 nodes and 200 ms per query. Retain incomplete attempts, and compare action, score, PV and nodes for jointly completed roots. Validate every returned PV and exact caller restoration. Instrumented time is not speed evidence.

Proceed to at most one isolated prototype only if at least 28 roots complete in both arms, all compared results agree, every repeated subtotal agrees, and repeated calls are at least 10% of positional subtotal calls across jointly completed roots and occur in at least eight such roots. Otherwise stop this family on this workload. A passed audit would only establish an opportunity: key construction and storage could exceed savings. No match, adoption, or tuning follows from the audit. Publish the frozen invoked source, harness, inputs, raw results and logs.
